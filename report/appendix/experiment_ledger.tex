\subsection{Chronological Sequence}
The experimental phases proceeded as follows:

\begin{enumerate}[label=\textbf{Phase \arabic*:},leftmargin=*]
    \item \textbf{Naive pipeline (V1):} 20 factors + LightGBM with contemporaneous target. IC = \InitialIC. \invalid{Rejected---target leakage detected.}
    \item \textbf{Leak detection (V2):} Date-shift scan, cross-fitting audit, survivorship correction. IC corrected to \CorrectedIC. \valid{Validated---clean pipeline established.}
    \item \textbf{Frozen baseline (V3):} PIT universe, rank normalization, 20-seed ensemble, 3-fold walk-forward. Mean OOS IC = \BaselineIC, NW $t$ = \NeweyWestT. \valid{Validated.}
    \item \textbf{Null infrastructure:} iid null, constant-label test, permutation audit. All passed. \valid{Validated.}
    \item \textbf{Portfolio diagnostics (DP-1/DP-1A):} Executable portfolio simulation, cost scenarios, quintile decomposition. U100 positive; U50 negative; Q1 dominant. \warn{Observed---signal concentrated in low liquidity.}
    \item \textbf{Residual ablation (Step 5):} RAW vs.\ RESID comparison. RESID improved U50 marginally but not sufficiently. \invalid{Rejected---failed profitability gate.}
    \item \textbf{Multi-horizon (MH-1R):} 3-month and 6-month targets. Both produced negative U50 returns. \invalid{Rejected---failed scalability gate.}
    \item \textbf{Termination:} OHLCV-only core strategy closed. Q1 preserved as frozen research sleeve. \valid{Decision recorded.}
\end{enumerate}
